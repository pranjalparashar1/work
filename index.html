  • Portfolio analysis toolInteractive · anonymised
    Reasoning for it (based on real client interactions)

    Client MF portfolios reviewed for drag factors: benchmark returns, fees, sectors, market-cap mix.

    Example: ₹76L portfolio, half direct, half regular plans. Standard framing: about 1% a year extra in fees (1.5% regular vs 0.5% direct).

    Reframed in rupees, per fund: fees paid on each regular plan against that fund's gain over its benchmark.

    Each fund's XIRR calculated from transaction files with actual cash-flow timing. An average fee % would misstate the cost.

    Client: "I didn't know I was paying this much for funds A, B and C. D is fine."

    The point was to build a tool → implement → test → iterate with feedback → test → ship, through knowing how to be a bridge between finance and tech.
